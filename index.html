How I got here

Two decades of shipping, mostly unglamorous.

Retail software Infrastructure Algorithms Enterprise & banking Platforms Founder

I've been writing code for over twenty years. It started with retail software — the system that ran a videotape rental store, back when that was a business. Inventory, memberships, late fees, and a counter full of people who needed it to work right now. The same shape of problem I work on today, with far worse tools.

I dropped out of college and won the university coding competitions anyway — both divisions, rookie and veteran, while still a rookie myself. Pascal and C, algorithms written to be tested rather than admired. It's the closest thing I have to a credential, and it's the one I'd point at.

What followed was less romantic and more useful. Keeping networks and machines alive. ERP posting routines, where a bug and a misstated ledger are the same event. Technology rollouts across a retail bank's branches, where the deadline is Monday morning and there is no version of done that excludes the branch in the middle of nowhere.

At the bank I automated my own job. Batch scripts walked the agency networks, inventoried every device, and produced the spreadsheet procurement bought from. Evidence gathered automatically, a purchase decided on deterministic data, a person approving. Nobody called that an agent in 2010 — but it is exactly the loop I build today.

Somewhere in there I started a business of my own and it failed. That taught me more about how companies actually run — cash, margin, the gap between a plan and a month-end — than any of the jobs did. I also spent a while teaching people to use computers, which is where I learned that if you can't explain a system plainly, you don't really understand it.

So the route into finance systems didn't come from the finance side, and it didn't come from a consultancy. It came from underneath: the networks, the hardware, the integrations, the rollouts that had to hold. That's why I'm willing to put agents near these systems now — and exactly why I'm careful about which parts.

{
    VendInvoiceJour jour;
    ttsbegin;
    while select forupdate jour
        where jour.InvoiceAmount > 0 && !jour.Posted
    {
        jour.Posted = NoYes::Yes;
        jour.update();
    }
    ttscommit;
}
